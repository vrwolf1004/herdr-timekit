# herdr-timekit

[English](README.md) | [**한국어**](README.ko.md)

herdr 사이드바 맨 아래 블록에 현재 시간, 세계 시간, 타이머, 카운터를 모아 보여 주는 플러그인입니다. AI 코딩 에이전트와 함께 작업하는 동안 시간을 계속 볼 수 있습니다.

## 대시보드 디자인

상세 패널(timekit pane에 열리는 화면):

```
╭──────────────────────────────────────────────╮
│             🐺  herdr-timekit  🌕            │
├──────────────────────────────────────────────┤
│ 🕒 시간                                      │
│   현재      16:02                            │
│ 🌐 세계     Seoul          17:23 KST         │
│             New York       04:23 EDT         │
│             Tokyo          17:23 JST         │
│             Paris          10:23 CEST        │
├──────────────────────────────────────────────┤
│ ⏳ 타이머                                    │
│   값        25:00           준비             │
│   진행      ████████████████                 │
├──────────────────────────────────────────────┤
│ 🔢 카운터                                    │
│   값        0               정지             │
├──────────────────────────────────────────────┤
│   [t] 시작/정지  [r] 초기화                  │
│   [c] 시작/정지  [0] 초기화                  │
│   [1-6] 프리셋 [w] 추가 [x] 삭제 [b] 디자인  │
╰──────────────────────────────────────────────╯
```

사이드바 블록(손목시계 모양 박스, `box_style: emoji_tulip`, 10가지 중 하나):

```
╔═══════════════╗
║🌷 🌷 🌷 🌷 🌷 ║
║   오후 4:02   ║
║     10/19     ║
║🌷 🌷 🌷 🌷 🌷 ║
╚═══════════════╝
```

박스에는 시각과 날짜가 나옵니다. 타이머가 돌면 타이머 값이, 카운터가 돌면 카운터 값이 대신 나옵니다. 타이머가 끝나면 글자가 `* 종료 *`와 `  종료  `로 번쩍입니다. 패널에서 `b`를 누르면 디자인이 바뀝니다.

## 설치

```sh
herdr plugin install vrwolf1004/herdr-timekit
```

## 빠른 시작

1. 플러그인을 설치하고 사이드바 줄을 추가합니다([사용법](docs/usage.ko.md#2-사이드바-설정)).
2. timekit pane을 클릭하고 `t`를 누르면 타이머, `c`를 누르면 카운터가 시작됩니다.
3. `w`를 누르고 `Seoul`처럼 도시 이름을 입력하면 세계 시간이 추가됩니다.

## 요구 사항

- herdr 0.9.0 이상
- Windows, Linux, macOS
- Python 3.9 이상 (Windows는 `python -m pip install tzdata`도 필요)
